# Deck-pitch-GreenCO

This repo currently holds two unrelated things:

1. **The GreenCO pitch deck** — `index.html` (self-contained, Raleway font,
   green palette), `README.md`.
2. **Planning artifacts for a separate project, "AI Designers" / Design Intel
   Engine** — see `docs/design-intel-plan.md` and the
   `.claude/skills/design-intel-engine/SKILL.md` skill. That project studies
   reference designers/studios (X profiles, portfolios, sites) to build an
   automated pipeline that distills their visual systems into reusable design
   tokens and a self-improving design skill. It is meant to live in its own
   dedicated repo (`design-intel-engine`) once bootstrapped — these files are
   the carried-over memory of the plan and target list so nothing is lost.

If asked to continue the design-intel project, read
`docs/design-intel-plan.md` first.
